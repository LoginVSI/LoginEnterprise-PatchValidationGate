# Contributing

See [the contributor guide](docs/contributing.md) for development dependencies, API review, code rules, fixtures and verification in Windows PowerShell 5.1 and PowerShell 7. Ordinary users can start with the [offline example](README.md#start-here) without installing those dependencies.

Run both offline suites and lint, plus affected scenario/workflow/skill checks, before proposing changes. Keep real captures and generated outputs private. CI checks are offline and do not establish live acceptance.
